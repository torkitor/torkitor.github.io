Imaging preprocessing · Python

RadAccord ↗

Checks retained source and candidate images against a declared preprocessing operation. It distinguishes sampling fidelity, coverage of the selected region of interest and the conditions for reusing measurements.

Designed to make image-processing assumptions inspectable before radiomic feature reuse. A satisfied sampling check does not imply that all features are equivalent or that a model is clinically validated.

Radiograph de-identification · Computer vision & OCR

DeID-Rx ↗

Winner of the IABiomed 2026 Treelogic challenge for visual de-identification of medical images.

A research pipeline for detecting, reading and redacting identifying text embedded in radiograph pixels. The project combines computer vision and optical character recognition, with a separate OCR-based assessment of residual readable text.

Developed for a hackathon and evaluated using synthetic identifying text on radiographs. Generalisation to real hospital annotations requires further validation; the repository documents the evaluation setting and limitations.
